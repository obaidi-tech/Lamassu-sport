# مقالاتك الخاصة

كل ملف هنا ينتهي بـ `.md` يُنشر مقالاً كاملاً باسم كاتبه في قسم «رأي ونقد».

## لنشر مقال جديد من GitHub

1. افتح ملف `_template.md` في هذا المجلد، وانسخ محتواه كله.
2. ارجع إلى المجلد واضغط **Add file** ثم **Create new file**.
3. سمِّ الملف بالإنجليزية دون مسافات وانتهِ بـ `.md`، مثل: `2026-11-03-iraqi-pros.md`
4. الصق القالب، واكتب العنوان واسم الكاتب والتاريخ ونص المقال.
5. اضغط **Commit changes**. يظهر المقال في الموقع خلال دقيقتين تقريباً.

## قواعد بسيطة

- الأسطر بين `---` و`---` في أعلى الملف هي معلومات المقال. لا تحذف علامتي `---`.
- اترك سطراً فارغاً بين الفقرات.
- السطر الذي يبدأ بـ `## ` يصبح عنواناً فرعياً.
- لإخفاء مقال دون حذفه، أضف سطر `draft: true` بين علامتي `---`.
- لتعديل مقال منشور: افتح ملفه، واضغط أيقونة القلم، وعدّل، ثم **Commit changes**.
- الملفات التي يبدأ اسمها بـ `_`، وهذا الملف، لا تُنشر.

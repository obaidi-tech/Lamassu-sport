# المقالات والأخبار اليدوية

كل ملف هنا ينتهي بـ `.md` يُنشر في الموقع:
- **مقال رأي** باسم كاتبه، في قسم «رأي ونقد». القالب: `_template.md`
- **خبر** في أي قسم إخباري، مع مصادره. القالب: `_news-template.md`

## لنشر مقال أو خبر جديد من GitHub

1. افتح القالب المناسب في هذا المجلد، وانسخ محتواه كله.
2. ارجع إلى المجلد واضغط **Add file** ثم **Create new file**.
3. سمِّ الملف بالإنجليزية دون مسافات وانتهِ بـ `.md`، مثل: `2026-11-03-iraqi-pros.md`
4. الصق القالب، واكتب العنوان واسم الكاتب والتاريخ ونص المقال.
5. اضغط **Commit changes**. يظهر المقال في الموقع خلال دقيقتين تقريباً.

## خانات الخبر

| الخانة | المعنى |
|---|---|
| `title` | عنوان الخبر |
| `category` | القسم، واحد من: `top5` الدوريات الخمس الكبرى، `orgs` المنظمات الدولية والقارية، `world` كرة العالم، `other_sports` رياضات عالمية، `nba` كرة السلة الأمريكية، `awareness` توعية ودراسات |
| `date` | تاريخ النشر ووقته |
| `sources` | المصادر، سطر لكل مصدر بالصيغة `الاسم \| الرابط`. يمكن حذف الخانة كلها |
| `featured` | اكتب `true` ليتصدّر الخبر الصفحة الرئيسية |
| `author` | اختياري: اسم من أعدّ الخبر |
| `image` | اختياري: صورة ترفعها إلى مجلد `images` هنا، مثل `images/photo.jpg` |

## قواعد بسيطة

- الأسطر بين `---` و`---` في أعلى الملف هي معلومات المقال. لا تحذف علامتي `---`.
- اترك سطراً فارغاً بين الفقرات.
- السطر الذي يبدأ بـ `## ` يصبح عنواناً فرعياً، و`### ` عنواناً أصغر.
- السطر الذي يبدأ بـ `- ` يصبح بنداً في قائمة نقطية.
- لإخفاء مقال دون حذفه، أضف سطر `draft: true` بين علامتي `---`.
- لتعديل مقال منشور: افتح ملفه، واضغط أيقونة القلم، وعدّل، ثم **Commit changes**.
- الملفات التي يبدأ اسمها بـ `_`، وهذا الملف، لا تُنشر.

# غرفة الأخبار الرياضية الآلية — النسخة التجريبية للموقع

محرك يجمع الأخبار الرياضية العالمية من مصادر مجانية عامة، ويختار **حتى 50 خبراً يومياً** حسب الأهمية، ويصوغها بالعربية بالذكاء الاصطناعي، ثم **يبني الموقع بنفسه** وينشره مجاناً على GitHub Pages.

لا يحتاج ووردبريس، ولا استضافة مدفوعة، ولا اشتراكات في وكالات، ولا مراسلين. التكلفة الوحيدة: استهلاك الذكاء الاصطناعي، ولاحقاً نطاق خاص إن أردت.

## ما في الموقع

- **الرئيسية:** "عدد اليوم" وفيه الخبر الأوسع تغطية في لوحة بارزة، ثم الأربعة التالية، ثم مقالات الرأي، ثم أقسام الأخبار.
- **مقياس التغطية:** بجانب كل خبر أشرطة تبيّن عدد المصادر المستقلة التي تناولته. هذا هو معيار الترتيب نفسه، معروضاً للقارئ.
- **صفحة الخبر:** النص، ثم صندوق "مصادر هذا الخبر" بروابطها وشارات "وكالة" و"جهة رسمية"، ورابط لطلب تصحيح.
- **مقالات الرأي:** ملخص بصياغة الموقع، مع اسم الكاتب والصحيفة ورابط المقال الأصلي. لا يُعاد نشر النص.
- **صفحات الأقسام، والأرشيف اليومي، وصفحة "سياسة الموقع"**.
- خلاصة RSS، وخريطة موقع لمحركات البحث، وصورة مشاركة مولّدة لكل خبر تظهر عند مشاركة الرابط.
- يعمل على الجوال، ويدعم الوضع الليلي، والخطوط محمّلة من الموقع نفسه (Cairo وNoto Naskh Arabic).

## كيف يعمل

```
مصادر مجانية → تجميع الخبر الواحد من ناشرين متعددين → تصنيف → درجة أهمية
  → اختيار ضمن الحصص وفوق الحد الأدنى للأهمية → كشف التكرار بين العربية والإنجليزية
  → صياغة عربية من الوقائع فقط → تحقق آلي
  → سليم: يُنشر فوراً | حساس أو مشكوك فيه: قائمة المراجعة
  → بناء الموقع ونشره
```

يعمل **كل ساعتين** من 06:00 إلى 22:00 بتوقيت الرياض، فتتوزع الأخبار على اليوم.

### الخمسون سقف لا هدف

لكل قسم حد أدنى للأهمية (`min_score` في `config/categories.yaml`). القصة التي لم تغطّها مصادر كافية لا تُنشر، حتى لو بقيت حصة القسم ناقصة. في الأيام الهادئة ينشر الموقع أقل، ولا يملأ الفراغ بأخبار ضعيفة. في الاختبار: من 23 قصة ضعيفة نُشرت 13 فقط.

| القسم | السقف اليومي |
|---|---|
| الدوريات الكبرى | 12 (3 لكل دوري كحد أقصى) |
| رياضات عالمية | 12 (2 لكل رياضة) |
| كرة قدم | 10 (2 لكل دولة) |
| دولي وقاري | 5 |
| كرة السلة الأمريكية | 3 |
| رأي | 3 (مقال واحد لكل كاتب) |
| أبحاث ودراسات | 3 |
| الأبرز (حصة مرنة لخبر قوي جداً فقط) | 2 |

## النشر اليدوي: مقالات وأخبار

يمكن نشر المقالات والأخبار يدوياً دون مفتاح الذكاء الاصطناعي ودون أي تكلفة. كل ملف `.md` في مجلد `content/posts` يُنشر في الموقع:
- **مقال رأي** باسم كاتبه، بالقالب `content/posts/_template.md`.
- **خبر** في أي قسم مع مصادره، بالقالب `content/posts/_news-template.md`. الخبر الذي فيه `featured: true` يتصدّر الصفحة الرئيسية.

الشرح الكامل في `content/posts/README.md`. يُعاد بناء الموقع تلقائياً خلال دقيقتين تقريباً من حفظ الملف.

## التواصل

في `config/site.yaml`: `contact_email` (بريد صفحة «تواصل معنا» وطلبات التصحيح)، و`owner_name` و`linkedin_url` (يُربط اسم صاحب الموقع بلينكدإن تحت مقالاته). أي خانة فارغة لا تظهر في الموقع.

## قائمة المراجعة

هذه الأخبار لا تُنشر آلياً، بل تُحفظ في مجلد `content/pending`:
- الوفيات، والقضايا، والعنصرية، والإيقافات، والمنشطات.
- الشائعات التي لم يؤكدها مصدران موثوقان.
- الخبر الذي ينقله مصدر واحد غير موثّق.
- أي خبر فيه رقم غير موجود في المصادر.
- ما يطلب الذكاء الاصطناعي نفسه مراجعته.

**للموافقة أو الرفض من الجوال أو الحاسوب:** افتح الملف في GitHub، اضغط أيقونة القلم، غيّر السطر:

```
"decision": ""
```
إلى `"decision": "publish"` (أو `"نشر"`) أو `"decision": "reject"` (أو `"رفض"`)، ثم اضغط **Commit changes**. يُعاد بناء الموقع خلال دقيقتين تقريباً. ما لا يُراجع خلال 3 أيام يُحذف تلقائياً.

## التركيب (مرة واحدة، نحو 15 دقيقة)

1. أنشئ حساباً على GitHub، ثم مستودعاً جديداً، وارفع إليه محتوى هذا المجلد.
2. **Settings → Pages → Source:** اختر **GitHub Actions**.
3. **Settings → Secrets and variables → Actions → New repository secret:** الاسم `ANTHROPIC_API_KEY`، والقيمة مفتاحك من console.anthropic.com (ابدأ برصيد 10–20 دولاراً).
4. في `config/site.yaml` غيّر `site_name` و`site_url` (رابط GitHub Pages، يظهر في صفحة Pages بعد أول نشر) و`contact_email`.
5. **Actions → newsroom → Run workflow** للتشغيل الأول. بعدها يعمل وحده.

> **المستودع العام أم الخاص؟** GitHub Pages مجاني للمستودعات العامة. للمستودع الخاص يحتاج خطة GitHub مدفوعة. محتوى المستودع هنا أخبار منشورة أصلاً، فلا ضرر من أن يكون عاماً. المفتاح السري لا يظهر أبداً لأنه محفوظ في Secrets.

**أول شيء بعد التركيب:** افتح تقرير التشغيل (Actions → آخر تشغيل → run-report) وتأكد أن المصادر تعمل. المصادر التي لا تعمل تُعطَّل في `config/sources.yaml` بإضافة `enabled: false`.

## على حاسوبك

```bash
pip install -r requirements.txt
cp .env.example .env              # ضع ANTHROPIC_API_KEY
python check_feeds.py             # افحص المصادر
python run.py --dry-run --all-day # معاينة كاملة دون نشر: public/index.html
python run.py --publish           # نشر فعلي إلى content/ وبناء الموقع في public/
python run.py --build-only        # تطبيق قرارات المراجعة وإعادة البناء فقط
```

### الموقع التجريبي دون إنترنت أو مفتاح
```bash
python tests/make_fixtures.py && python tests/build_demo.py   # يفتح في demo_site/index.html
```
الأخبار فيه **وهمية** لأغراض العرض، وعليها شريط تنبيه.

## الإعدادات

| الملف | ما تغيّره |
|---|---|
| `config/site.yaml` | الاسم، الرابط، البريد، السقف اليومي، أوقات التشغيل، وضع النشر (`auto` / `draft`)، النموذج، أسماء الشهور (`gulf` نوفمبر / `levant` تشرين الثاني) |
| `config/categories.yaml` | الحصص، الحد الأدنى للأهمية، الحد لكل دوري/رياضة/دولة، الكلمات المفتاحية |
| `config/rules.yaml` | أوزان الناشرين، الكلمات الحساسة، كلمات الشائعات، قاموس الأسماء العربية |
| `config/sources.yaml` | المصادر |
| `templates/` و`site_assets/style.css` | تصميم الموقع |
